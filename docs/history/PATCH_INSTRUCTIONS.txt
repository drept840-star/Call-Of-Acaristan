CALL OF ACARISTAN - INTERNET MULTIPLAYER PATCH

1. Back up your project.
2. Extract this ZIP into the project folder containing acaristan.py and build.bat.
   Replace the matching files. This is a patch, not the entire game.
3. Delete assets/bin/cloudflared.exe if present. It is obsolete; build.bat
   copies assets, so leaving it there would unnecessarily bundle it.
4. Run build.bat on Windows x64 to rebuild the game EXE. Python and the game's
   dependencies must be installed on the BUILD computer, not the players' PCs.
5. Both players use the rebuilt game: MULTIPLAYER > ARENA MATCH.
   Host chooses HOST MATCH and waits for readiness; friend uses JOIN MATCH
   and pastes the displayed code/address. No Hamachi installer is needed.

The separate Host Acaristan Server / Join Acaristan executables are lobby/chat
utilities, NOT the playable arena server. Their join-only build needs no bore.

Verification: compileall passed; five focused unit tests passed; real bore TCP
round-trips passed through a local relay and the public bore.pub relay; CLI host
with --tunnel --no-forward published a bore address and shut down cleanly.
Windows EXE build, pygame smoke tests, and two-device gameplay are NOT verified.
Free bore.pub has no uptime guarantee and relays UNENCRYPTED traffic. Do not
send secrets in game chat. This is a friends/testing solution, not production
hosting. atexit cleanup covers normal exit and Python exceptions, NOT force-kill
or native crashes. See RESUME_PROMPT.txt for remaining release checks.
